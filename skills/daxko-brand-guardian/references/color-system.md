## 2. Gradient Blends

Gradients add depth and motion to brand materials. Only use the defined blends below. Never create arbitrary gradients from unrelated palette colors.

### Single-Color Blends

For each primary color family, a subtle blend between two tints is acceptable as a background fill. Use for section backgrounds, card fills, and subtle visual depth.

| Family | Start | End | CSS |
|--------|-------|-----|-----|
| Vitality | `#F73D8A` (500) | `#C90D4C` (700) | `linear-gradient(90deg, #F73D8A, #C90D4C)` |
| Champion | `#FDD48A` (200) | `#FA9E25` (400) | `linear-gradient(90deg, #FDD48A, #FA9E25)` |
| Agility  | `#2EAAFF` (400) | `#0070D1` (600) | `linear-gradient(90deg, #2EAAFF, #0070D1)` |
| Core     | `#D425D4` (600) | `#90188C` (800) | `linear-gradient(90deg, #D425D4, #90188C)` |

**Direction:** 90deg (left-to-right) default. 180deg (top-to-bottom) for vertical formats.

### Multicolor Blends

Multicolor blends cross two color families. Use very sparingly — intended for full-bleed colored backgrounds only. Limit to 2 colors; 3-color blends should be rarely used.

| Name | Start | End | CSS |
|------|-------|-----|-----|
| Core → Vitality *(primary brand gradient)* | `#B81CB5` (Core 700) | `#E8236B` (Vitality 600) | `linear-gradient(90deg, #B81CB5, #E8236B)` |
| Core → Agility | `#B81CB5` (Core 700) | `#038BED` (Agility 500) | `linear-gradient(90deg, #B81CB5, #038BED)` |
| Champion → Vitality | `#FBB03B` (Champion 300) | `#E8236B` (Vitality 600) | `linear-gradient(90deg, #FBB03B, #E8236B)` |

**Direction:** 90deg default. 180deg acceptable for tall/vertical formats.

**Application:** Hero banners, keynote slides, premium asset headers. Apply over large surface areas, never on small elements.

## 3. Color Proportions

The brand uses five named proportion roles that map to the five color families. These are guidelines for visual balance, not rigid rules.

| Role | Color Family | Description |
|------|-------------|-------------|
| Core | Core (purple) | The anchoring tone — used for premium accents, gradient starts, and deep branded surfaces. |
| Flex | Flex (gray) | The neutral backbone — adjusts based on format. Text-heavy layouts lean toward lighter Flex values; visual layouts use darker values for contrast. |
| Agility | Agility (blue) | Digital-emphasis contexts weight Agility more heavily than other accents for tech-forward impressions. |
| Champion | Champion (amber) | Accent and highlight usage — small pops that draw the eye to CTAs, key stats, or featured content. |

**Rule:** Prioritize readability and visual hierarchy over rigid ratio adherence. A social media graphic may be 80% gradient with white text, while a whitepaper cover may be 90% white with a Vitality accent bar.

## 4. Status Indicator Colors

Status indicator colors are used for UI status elements — form fields, toasts, validation states, and system feedback. These have strict usage boundaries.

| Token | Hex | Usage |
|-------|-----|-------|
| Success | `#037C57` | Positive confirmation, success toasts, completion states, form success validation |
| Caution | `#FBB03B` | Non-critical warnings, advisory states — same hex as Champion 300 |
| Warning | `#E8236B` | Alert states, form validation errors, urgent system messages — same hex as Vitality 600 |

**Hard rules:**
- **Success (`#037C57`) is ONLY for status indication elements.** Never use it in general branding, marketing assets, campaign graphics, or decorative contexts.
- Caution and Warning share hex values with Champion 300 and Vitality 600 respectively — context determines the role. In marketing, these are brand accent colors. In UI, they are status indicators.
- The product design system green scale (`#008011` and variants) remains reserved for product UI success states only and is separate from the status indicator `#037C57`.

## 8. Usage Rules

### Backgrounds

| Context | Recommended Colors |
|---------|--------------------|
| Page / section background | `#FFFFFF` (white), Flex 050 (`#F6F6F6`), or the Brand / Agility gradient for hero sections |
| Card surface | `#FFFFFF` on colored backgrounds, Flex 050 (`#F6F6F6`) on white backgrounds |
| Hero banner | Brand gradient (`#B81CB5` → `#E8236B`) or Agility gradient (`#2EAAFF` → `#0070D1`) |
| Dark section | `#000000` or Agility 800 (`#014C8B`) |
| Sidebar / navigation | Agility 700 (`#0059A9`) or `#FFFFFF` |

### Text

| Context | Recommended Colors |
|---------|--------------------|
| Primary body text | `#000000` on light backgrounds, `#FFFFFF` on dark/gradient backgrounds |
| Secondary / supporting text | Flex 600 (`#595959`) or Flex 500 (`#6D6D6D`) |
| Headings on light backgrounds | `#000000` |
| Headings on dark backgrounds | `#FFFFFF` |
| Links | Agility 500 (`#038BED`) |
| Link hover | Agility 700 (`#0059A9`) |

### Buttons and CTAs

| Button Type | Fill Color | Text Color | Hover Fill | Border |
|-------------|-----------|------------|------------|--------|
| Primary CTA | Vitality 600 (`#E8236B`) | `#FFFFFF` | Vitality 700 (`#C90D4C`) | None |
| Secondary CTA | Flex 600 (`#595959`) | `#FFFFFF` | Flex 700 (`#4F4F4F`) | None |
| Ghost / Outline | `transparent` | Vitality 600 (`#E8236B`) | Flex 050 (`#F6F6F6`) | Vitality 600 |
| Disabled | Flex 200 (`#D1D1D1`) | Flex 400 (`#888888`) | — | None |

### Accents and Decorative Elements

- Use Vitality 400 (`#FD69AA`) for decorative underlines, pull-quote borders, icon tints, and secondary highlights.
- Use Agility 400 (`#2EAAFF`) for data visualization accents, chart elements, and interactive affordances.
- Use Champion 300 (`#FBB03B`) for award highlights, stat callouts, and warm accent pops.
- Use Brand Fun Colors only for campaign-specific or event-specific materials where personality and playfulness are appropriate.

### Icons

Each color family has a dedicated icon set (Duotone Thin style, 1,535 icons per set):
- **Agility icons** — `#038BED` (blue)
- **Vitality icons** — `#E8236B` (pink)

## 9. Accessibility Contrast Requirements

All color pairings must meet WCAG 2.1 AA contrast ratios at minimum:

- **Normal text (< 18px):** 4.5:1 contrast ratio minimum
- **Large text (>= 18px bold or >= 24px regular):** 3:1 contrast ratio minimum
- **UI components and graphical objects:** 3:1 contrast ratio minimum

## 10. Don'ts

These are hard rules. Violating them produces off-brand, confusing, or inaccessible output.

1. **Never use success green (#008011 or any green) in marketing materials.** Green is reserved exclusively for product UI status indicators. It is not part of the marketing color palette.

2. **Never create custom gradients** from arbitrary palette colors. Only use the two defined gradients: Brand gradient (`#B81CB5` → `#E8236B`) and Agility gradient (`#2EAAFF` → `#0070D1`).

3. **Never use light shades (050-300) as primary backgrounds for hero sections.** They are too light and low-contrast for large surface areas with white text. Use them only as subtle tints, card fills, or background accents.

4. **Never pair two similar brand shades** as foreground and background (e.g., Vitality 600 text on Vitality 400 background). This creates unreadable, clashing compositions.

5. **Never use Brand Fun Colors as primary or dominant colors** in any layout. They are accent-only and must never exceed roughly 10-15% of the visual surface area.

6. **Never substitute product design system tokens for marketing brand family colors** (or vice versa) in contexts where the distinction matters. Marketing materials use the five brand families (Agility, Vitality, Core, Champion, Flex). Product UI uses the Primary Default/Success/Warning/Danger scales.

7. **Never apply color at the expense of readability.** If a color pairing fails WCAG AA contrast, do not use it regardless of brand preference. Swap to a darker or lighter shade from the same family.

8. **Never use pure red (#FF0000) or pure green (#00FF00)** anywhere. These are not Daxko colors. Use the defined Danger and Success scales instead.

9. **Never use Champion shades as text colors on white backgrounds.** They are too warm and low-contrast for readability. Use them only as fills, backgrounds, or icon accents.

10. **Never place important text on a gradient without ensuring contrast.** Test the lightest point of the gradient against the text color to confirm readability.
