# Agent 33 — Content Migration — teammate guide

**Skill:** `daxko-content-migration` · **Owner:** Abid Siddiqui · **Version:** 1.10.0

## What it does
When a client's old website (a YMCA, JCC, club or studio — or a Daxko site if you ask) is rebuilt, it moves the content: a list of every old page, a move map (old address → new address → keep, rewrite, merge or drop, and why), cleaned text ready to paste, the redirect list and an after-move check list. It asks a few short questions at a time until it has the old pages, the new address map and the switch-over date. With your yes, it can read the old CMS, and — only after showing you the exact list and getting your yes — create draft, unpublished pages in the new CMS.

## Requests to try
- "Move the old site's pages into the new site"
- "Content inventory and migration plan for this JCC's old site"
- "Which old pages do we keep, merge or drop?"

## Good to know
- New addresses come only from Agent 28 — Information Architecture's old-to-new map (or a list you paste). It never makes one up.
- It keeps the old wording. Old facts (dates, prices, staff) are flagged for checking, never changed.
- It never publishes, never sets redirects live, never deletes old pages.
- A "yes" only counts when you type it in the chat.

## What it will NOT do — and who does
| Ask | Owner |
|---|---|
