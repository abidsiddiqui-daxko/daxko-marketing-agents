# Event Landing Page Examples

Load this file when generating 4D (Landing Page) assets. Mirror the structure, section order, copy length, CTA placement, placeholder format, and thank-you page format shown below.

---

## Format Standards

**Page structure:** Every landing page follows this section order:
1. Hero (H1 + subheadline + form embed + primary CTA button)
2. Event overview / "where to find us" (H2 sections per event/day)
3. Product/value sections (2–3, each with H2 + supporting copy + optional image note)
4. Social proof (testimonials or stats)
5. Closing CTA section (final H2 + supporting copy + CTA button)
6. Thank-you page (separate URL slug; includes confirmation message + what happens next)

**Placeholders:** Use `{{double curly braces}}` for unfilled details — consistent with HubSpot/CMS token format. Examples: `{{Room}}`, `{{Speakers}}`, `{{Moderator}}`, `{{Giveaway details}}`, `{{Location}}`. Flag all placeholders for the user in a separate "Needs Fill-In" note at the end of the page copy.

**CTAs:** The primary CTA appears in the hero and repeats at the end of every major section (at minimum: hero, middle of page, closing section). Common labels: "Request a Meeting," "Book Your Suite Time," "Book a Meeting," "Book Your Spot."

**Form embed:** The hero always includes a form. Standard fields: First Name, Last Name, Email, Organization/Gym Name, Phone (optional). Note form fields in the copy as `[FORM EMBED: fields]`.

**UTM parameters:** Note the UTM string in the production notes section. Format: `utm_source=[brand]&utm_medium=landing_page&utm_campaign=[campaign_name]`

**URL structure:** Provide suggested URL slug and thank-you page slug. Format: `landing.[brand].com/[event-year]` and `landing.[brand].com/[event-year]-thank-you`

**Logos/images:** Note where logos, image modules, or product screenshots appear. Claude generates copy only — flag image needs for the design team.

## Writing Notes

- **Duplicate last year's LP:** When the user says "duplicate last year's" or provides a prior URL, that means keep the same section structure and UTM pattern — but update all content, dates, sessions, speakers, and CTAs. Never assume last year's copy is current.
- **Needs Fill-In section:** Always end the page copy with a consolidated list of every `{{placeholder}}` that needs to be filled before launch. This saves review time.
- **Form fields:** Standard set is First Name, Last Name, Email, Org/Gym Name, Phone (optional). Add or remove based on what's in the brief.
- **Meeting incentives:** When an incentive exists (gift card, giveaway, Starbucks), work it into the hero subheadline or CTA label and reinforce in the closing CTA section.
- **Thank-you pages:** Always produce the thank-you page alongside the main page. It's easy to skip but important for post-submission experience.
- **Do not reference Daxko ownership** in SugarWOD/Zen Planner/boutique-market pages. Only use Daxko branding on enterprise-market pages.
