# HubSpot Campaign Email Examples

Load this file when generating 4A (HubSpot Campaign) assets. Mirror the structure, length, tone, send metadata, and CTA format shown below.

---

## Format Standards (apply to every email)

Every email must include all of these fields before the body:

```
From Name: [Team name — e.g. "The Daxko Team" or "The SugarWOD Team"]
From Email: marketing@[brand].com
Reply-to Email: marketing@[brand].com
Send Date: [Specific date or relative timing — e.g. "Feb 11" or "3 weeks before event"]
Send List: [Audience description — e.g. "Full HFA List" or "YMCA / NAYDO Audience"]
Subject Line: [Complete subject — never leave blank; write a placeholder if TBD]
Preview Text: [90 chars max]
```

**Merge tags:** Use `{{First Name}}` for personalization. Do not use other bracket formats.

**CTA format:** Every email ends with a single CTA button label (e.g., `[Request a Meeting with the Team]`) and a sign-off from the team name.

**Series length:** Default to 5 emails unless the user specifies otherwise. See arc below.

---

## Standard 5-Email Arc

| # | Theme | Timing | Notes |
|---|---|---|---|
| 1 | Announcement / Event overview | 3–4 weeks before event | Establishes presence; all events/activations in one place |
| 2 | Product or ecosystem focus | ~2.5 weeks before | Feature or partner story; deeper than Email 1 |
| 3 | Sessions / speaking / agenda | ~2 weeks before | Drive attendance to sessions; use real speaker names/times |
| 4 | Booth / demo experience | ~1 week before | What to expect at the booth; book a meeting CTA |
| 5 | Final reminder / see you there | 3–5 days before | Quick recap of where to find us; last chance to book |

Post-event: If requested, 2-email post-event series (recap + follow-up) sends 1–3 days and 1 week after the event.

## Writing Notes

- **Subject lines:** Write them for every email. Never leave blank. If a theme is clear but the line isn't finalized, write a working draft and flag it.
- **Emoji use:** NAYDO/nonprofit emails use emoji sparingly but warmly. Enterprise/HFA emails skip emoji or use them only in subject lines. Match the market.
- **Session details:** Use real speaker names, times, and room numbers when available. Use `{{Room}}` and `{{Speakers}}` as placeholders only when the information isn't yet confirmed — flag these as needing fill-in.
- **Image placeholders:** Note `[partner logo image]`, `[photo collage]`, etc. where visuals are expected. Claude generates copy only; flag image needs for the design team.
- **Incentives:** When an event has a meeting incentive (gift card, giveaway, margaritas), weave it into Email 1 and reinforce in Email 2. Mention giveaway logistics as `{{Giveaway details placeholder}}` if not confirmed.
