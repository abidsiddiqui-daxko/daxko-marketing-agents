# Social Post Examples

Load this file when generating 4C (Social Campaign) assets. Mirror the format, copy length, hashtag approach, image direction, and role-based structure shown below.

---

## Format Standards

**Primary platform:** LinkedIn (B2B focus). Instagram used for consumer/community-forward markets (SugarWOD/CrossFit, boutique gyms). Confirm platform mix before generating.

**Primary CTA for all posts:** Drive to the event landing page. All copy should reference or link to it.

**Individual vs. team posts:** Some events produce role-based posts for individual team members to post from their own profiles (Sales/AM/AE, booth team) in addition to brand-page posts. Ask the user if individual team posts are needed.

**Hashtags:**
- Always ask for show-specific hashtags first
- If user wants research: use web search to find official event hashtag, organizer social handle, and 3–5 relevant industry hashtags before generating
- Standard count: event hashtag + 2–3 industry hashtags per post; do not pad with generic tags
- Place hashtags at the end of captions, not embedded in copy

**Image direction:** Note the recommended format (static image, carousel, motion graphic, video, collab post) and any specific visual guidance. Claude generates copy only — flag image/video production needs for the social/design team.

**Speaker/session posts:** Only include if there is a confirmed speaking opportunity at this event. Ask the user to confirm before generating.

**Partner/collab posts:** If a sponsorship includes collab posts with a partner account (e.g., WheelWOD), note the collab account handle and apply an adapted tone — community-first, no product sell in sponsored/collab content.

---

## Standard 5-Post Set

| Post | Format | Timing | CTA |
|---|---|---|---|
| 1. Announcement | Static image or motion graphic | 2–3 weeks before event | Landing page link in bio |
| 2. Speaker/session | Static image or short video | 1–2 weeks before event | "Add to your agenda" / landing page |
| 3. Partner / ecosystem | Carousel or static with logos | 1–2 weeks before event | Landing page or partner link |
| 4. Book a meeting | Static image | 5–7 days before event | Direct booking link / landing page |
| 5. See you next week | Static or motion graphic | 3–5 days before event | Landing page (last chance) |

*If no speaking opportunity: replace Post 2 with an alternative (booth preview, product highlight, or additional partner post) and note to the user.*

## Writing Notes

- **Individual posts vs. brand posts:** When individual posts are needed, produce two versions — one for the sales/AE team (personalized, meeting-booking focus with individual link) and one for the booth/support team (community and event focus, shared landing page link).
- **Collab/sponsored posts:** Always apply partner-first tone. Product messaging is secondary or absent. Get collab account approval and branded assets from the partner before publishing.
- **Placeholders:** Use `{{Room}}`, `{{Speakers}}`, `{{Location}}` for session details not yet confirmed. Flag these for the user before publishing.
- **Image production:** Claude generates copy and image direction notes only. Flag all video and graphic production needs for the social/design team.
- **Post timing:** Always suggest timing relative to the event date, not absolute dates. The social team will schedule based on the production calendar.
