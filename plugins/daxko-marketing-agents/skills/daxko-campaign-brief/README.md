# Agent 63 — Non-Profit · Agent 64 — Club · Agent 65 — Boutique Campaign & Content Strategist

**Tell it the market, the segment and the goal, and it writes the campaign brief — in the exact sections Daxko's playbooks require — ready to hand to the writers.** One skill covers all three campaign strategists (the planning half).

**Business owner:** Abid Siddiqui · **Skill name:** `daxko-campaign-brief` · **Batch 2** · first published v1.7.27

## Requests to try
> Plan a Q1 campaign for mid-size YMCAs.

> Campaign brief for JCCs evaluating Amilia.

> Campaign brief for multi-location clubs that want to leave ABC Fitness.

> Messaging for a BJJ studio switcher campaign.

> What campaigns should we run for Boys & Girls Clubs next quarter?

## What you get back
1. **The brief** in the market's own sections — Nonprofit 9, Club 7, Boutique 7 — each line traced to a file
2. **A hand-off block** Agent 13 — Content Production writes the assets from
3. **A guardrail check** (voice, banned words, no roadmap AI, segments kept separate)
4. What isn't on file, the Key Result (quoted), one next step, and the files it read

## Good to know
- It uses **approved proof only**. If a segment has none on file (YMCA and BGC case studies are still pending), it says so.
- It never invents dates or seasons — timelines come back as "Weeks 1–3 — confirm dates" unless you give dates.
- It keeps segments apart: a JCC brief is not a YMCA brief; martial arts is not CrossFit.
- It never positions AI Agents, Member Intelligence 360° or Smart Sending as available.
- Who signs off a brief isn't on file — it says "confirm who signs off".
