# ❌ BAD — do not produce anything like this

> 🔴 **WARNING. Every piece of copy in section A of this file is WRONG and must never be copied,
> adapted or reused.** It is reproduced so the failure is recognisable, because this failure reads
> *better* than the good one. It is fluent, confident, and almost entirely invented.
>
> **This is the archetype's actual failure mode.** A reviewer that lacks a fact refuses. A writer
> that lacks a fact invents one — and invention comes out sounding like marketing, which is exactly
> why nobody catches it.

**The request that produced it** — the same request as `good-boutique-package.md`:

> "We're launching Flex Fees to boutique studios next month. Give me two social posts, a launch
> email, two ad variants and the landing page hero, and make sure they all say the same thing."

## Section B — everything wrong with it

**Twenty-two faults.** Each one names the rule and the bundled file it breaks.

### The invented facts — the reason this example exists

| # | What was invented | Why it is invention |
|---|---|---|
| 1 | **"23% more revenue"**, repeated in three pieces | No bundled file contains this figure. The only sourced Flex Fees outcome is CrossFit 1926's **+$10,690 with membership down 4%** (`references/boutique-playbook.md`). ## The one sentence worth remembering

**Every invented claim in section A would have passed unnoticed if the copy had simply been a bit
less bold.** "Studios recover 23% more revenue" is caught because it is specific. "Most studios see
a meaningful lift" is the same invention and reads as reasonable caution. **If no bundled file says
it, it is a `[PLACEHOLDER]` — at every level of vagueness, including the vaguest.**
