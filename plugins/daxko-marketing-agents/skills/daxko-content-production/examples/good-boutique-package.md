## 3. Consistency check

| Piece | Core message | The one action | Claim set | Deliberate difference |
|---|---|---|---|---|
| Social post 1 | ✅ | ✅ See It in Action | ✅ $2,404.41 / $10,690.08 / 4% | none |
| Social post 2 | ⚠️ | ✅ See It in Action | ✅ $2,404.41 / $10,690.08 / 4% | Proof led; compresses the mechanism to one clause and drops the "your prices do not move" reassurance |
| Launch email | ✅ | ⚠️ Book a Walkthrough | ✅ full breakdown incl. 22.5% | Different CTA label, same destination; only piece carrying the percentage |
| Ad variant 1 | ✅ | ✅ See It in Action | ✅ $2,404 / $10,690 rounded to whole dollars | Rounds the cents for ad length — the claim is unchanged |
| Ad variant 2 | ✅ | ✅ See It in Action | ⚠️ No figure cited | Carries the mechanism with no number |
| Landing page hero | ✅ | ⚠️ Book a Walkthrough | ✅ full breakdown incl. 22.5% | Different CTA label, same destination |

**Where the pieces deliberately differ**

1. **Social post 2 and Ad variant 2 each carry half the message, not all of it.** Short-form copy
   cannot hold both the proof and the mechanism without reading as a list. They are written as a
   pair: whichever runs alone, the other half is in the landing page hero it points at.
2. **The email and the landing page hero say "Book a Walkthrough" where the social and ad copy say
   "See It in Action".** Same destination, same action. The longer formats can ask for a specific
   commitment; the short ones need the lower-friction label.
3. ⚠️ **Ad variant 2 cites no figure, and `references/banned-words.md` requires a specific proof
   point in boutique copy.** This one is a genuine weakness, not a considered trade-off. It is
   flagged rather than papered over: either add the figure and lose the shortest line, or run it only
   alongside Ad variant 1. **Your call, not mine.**
4. ⚠️ **No piece carries an owner-time-back angle, and `references/banned-words.md` requires one for
   boutique.** This is not an oversight and it cannot be fixed by writing harder: **no bundled file
   attributes any time saving to Flex Fees.** Every sourced Flex Fees outcome is revenue or margin.
   Inventing "hours back" to satisfy the framing rule would break the larger rule. **The requirement
   is declared unmet and left with the human** — see section 4, row 5. *This is the behaviour being
   taught: when two rules cannot both be met, say which one you broke and why, rather than quietly
   satisfying the smaller one with an invention.*
5. **Ad variant 1 rounds $2,404.41 to $2,404 and $10,690.08 to $10,690.** Dropping cents for ad
   length does not change what is claimed, and the exact figures are carried by the email and the
   hero. Rounding **up**, or rounding a percentage, would be a different matter.

## Six things this example is teaching

1. **Four placeholders, no invented facts.** A launch date, a URL, a quote and the novelty claim were
   all wanted, and none is in any bundled file. None was guessed, and none was softened into
   something vague — "launching soon" would have been the same invention with the edges filed off.
2. **The proof point is cited once and reused unchanged.** The same figures appear in the same form in
   every piece that carries them. A package where one figure is worded three ways is a package
   somebody will have to reconcile by hand.
3. **The consistency check admits two weaknesses.** Row 3 says Ad variant 2 breaks a boutique framing
   rule; row 4 says the package breaks another one that **cannot** be met from bundled sources. Both
   leave the decision with the human. A consistency check that only ever agrees with itself is
   decoration.
4. **The art-direction note is in words only.** No hex value, no font, no layout — those belong to
   Agent 29 — UX/UI Design, and `visual-brand/` is not bundled in this skill at all.
5. **One next step, phrased as a sentence to reply to.** Not a numbered menu: on claude.ai a skill
   fires by matching words, and "2" matches nothing.
6. 🔴 **Precedence beats popularity.** Three bundled files say one thing about the CrossFit 1926
   figure and one file says another. The package follows the **single file that itemises** over the
   three that summarise, uses the smaller and better-evidenced number, and puts the disagreement in
   section 4 to be fixed at source. **A claim is not safer because more files repeat it** — and one of
   those three files instructs writers to repeat it, which is how a wrong figure becomes standard.
