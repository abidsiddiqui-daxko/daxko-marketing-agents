# ✅ GOOD — a boutique multi-channel package

**This is the standard.** Read it before you write. The template gives you the shape; this gives you
the bar — how tightly a core message binds the pieces, how a proof point is cited, how an ungrounded
claim is handled instead of invented, and how honest the consistency check is.

**The request that produced it**

> "We're launching Flex Fees to boutique studios next month. Give me two social posts, a launch
> email, two ad variants and the landing page hero, and make sure they all say the same thing."

**Why this is a good package, in one line each:**

- The core message was locked **before** any piece was written, so all six pieces say one thing.
- Every number in the copy is traced to a bundled file, by name.
- Three things a human wanted are **not** in the copy as facts, because no bundled file supports
  them. They are visible `[PLACEHOLDER]`s, listed in section 4. **That is the behaviour being taught.**
- The consistency check names a real divergence instead of confirming everything matches.
- It offers **one** next step, as a sentence the person can reply with.

## 3. Consistency check

| Piece | Core message | The one action | Claim set | Deliberate difference |
|---|---|---|---|---|
| Social post 1 | ✅ | ✅ See It in Action | ✅ $10,690 / 4% | none |
| Social post 2 | ✅ | ✅ See It in Action | ✅ $10,690 / 4% | Proof only — the time-back half of the message is absent |
| Launch email | ✅ | ⚠️ Book a Walkthrough | ✅ $10,690 / 4% | Different CTA label, same destination |
| Ad variant 1 | ✅ | ✅ See It in Action | ✅ $10,690 / 4% | none |
| Ad variant 2 | ⚠️ | ✅ See It in Action | ⚠️ No figure cited | Carries the time-back half of the message with no number |
| Landing page hero | ✅ | ⚠️ Book a Walkthrough | ✅ $10,690 / 4% | Different CTA label, same destination |

**Where the pieces deliberately differ**

1. **Social post 2 and Ad variant 2 each carry half the message, not all of it.** Short-form copy
   cannot hold both the proof and the time-back angle without reading as a list. They are written
   as a pair: whichever runs alone, the other half is in the landing page hero it points at.
2. **The email and the landing page hero say "Book a Walkthrough" where the social and ad copy say
   "See It in Action".** Same destination, same action. The longer formats can ask for a specific
   commitment; the short ones need the lower-friction label.
3. ⚠️ **Ad variant 2 cites no figure, and `references/banned-words.md` requires a specific proof
   point in boutique copy.** This one is a genuine weakness, not a considered trade-off. It is
   flagged rather than papered over: either add the figure and lose the shortest line, or run it only
   alongside Ad variant 1. **Your call, not mine.**

## Five things this example is teaching

1. **Three placeholders, no invented facts.** A launch date, a URL, a quote and the novelty claim
   were all wanted, and none is in any bundled file. None was guessed, and none was softened into
   something vague — "launching soon" would have been the same invention with the edges filed off.
2. **The proof point is cited once and reused unchanged.** $10,690 and 4% appear in the same form in
   every piece that carries them. A package where the same figure is worded three ways is a package
   somebody will have to reconcile by hand.
3. **The consistency check admits a weakness.** Row 3 of the deliberate-differences list says Ad
   variant 2 breaks a boutique framing rule and leaves the decision with the human. A consistency
   check that only ever agrees with itself is decoration.
4. **The art-direction note is in words only.** No hex value, no font, no layout — those belong to
   Agent 29 — UX/UI Design, and `visual-brand/` is not bundled in this skill at all.
5. **One next step, phrased as a sentence to reply to.** Not a numbered menu: on claude.ai a skill
   fires by matching words, and "2" matches nothing.
