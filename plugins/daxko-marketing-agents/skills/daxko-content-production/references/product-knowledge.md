> `verticals/nonprofit-playbook.md` — dated, specific, and carrying Daxko's own AI guardrail *"Always pair

> **Why this mattered more than a normal documentation error.** Two source-of-truth files gave opposite
> answers on whether a product had shipped, and an agent that writes customer-facing copy reads **both**
> for most requests. Read this file and it wrote *"available today"*; read the playbook and it wrote
> *"coming Q3 2026."* One of those is a **false product claim to a customer** — the kind a sales team
> gets held to. Found on 2026-09-17 while writing the test suite for Agent 13 — Content Production,
> before a single line of copy had been generated.
>
> **Fixed here, in the source, not inside any skill** — per non-negotiable 17, so every agent that ever
> bundles this file inherits the correction. `verticals/nonprofit-playbook.md`'s tier table remains the
> authority on delivery status; this section now agrees with it rather than contradicting it.

capability is available today."* A capability's name is not permission to say it ships.
