# Agent 28 — Information Architecture — teammate guide

**Skill:** `daxko-information-architecture` · **Owner:** Abid Siddiqui · **Version:** 1.7.36

## What it does
Plans how a website is organised — the page tree (sitemap), main and footer menus, web addresses and what each page is for — for a Digital Services client's site or a Daxko site. For an existing site it gives a new structure, a list of changes and an old-to-new address map (redirect map). It first asks up to 3 short questions: what the site must hold, who visits and why, and anything fixed.

## Requests to try
- "Plan the sitemap for a JCC's new website" (then paste programs and locations)
- "Restructure this club's navigation" (paste the current pages)
- "What pages does this YMCA site need?"

## Good to know
- Pages, programs and locations come only from you; anything it adds is marked "proposed" with a reason.
- No "most visited" claims unless you paste numbers.
- It uses a nonprofit client's own words (a YMCA "branch", a JCC "center", a Boys & Girls Clubs "Club").
- It builds nothing and sets no redirects live.
