# Agent 8 — CMO Orchestrator — teammate guide

**Skill:** `daxko-cmo-orchestrator` · **Owner:** Abid Siddiqui · **Version:** 1.10.1

## What it does
For ONE goal, campaign or piece of work, it tells you **which of our agents to use, in what order**, what each one needs from you, what it hands to the next one, where the brand check sits, and which Daxko Key Result the work serves (quoted word for word from the goals file). It also gives you the first line to type into each agent. It plans the route — it does not do the agents' work.

## Requests to try
- "Which agents should we use for the Giving Tuesday push?"
- "Agent workflow for our Q1 YMCA campaign"
- "Where do I start with the agents for this?"

## Good to know
- It shows a 10-item checklist and asks you in short rounds (up to 3 questions at a time) until it has what it needs — or say "go ahead with what you have".
- It knows every Daxko agent and skill, and says plainly when a step has no agent (for example the parked automations) and a person must do it.
- If you ask, it can add the plan's steps as tasks in **your** Asana project — it first shows you every task and waits for your "yes" in the chat. It never sends, publishes, launches or deletes anything.

## What it will NOT do — and who does
| Ask | Owner |
|---|---|
| Turn our OKRs into the quarter plan, rank initiatives | Agent 2 — OKR Copilot |
| The go-live run-sheet across channels | Agent 56 — Campaign Workflows |
| Run a Digital Services client's website project | Agent 24 — Agency Orchestrator |
| Write the brief, the copy or the assets | the agent named in each step |
| Send, publish, launch or spend | a person — the campaign owner |
