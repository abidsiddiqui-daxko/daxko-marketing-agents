| What it said | Rule it breaks |
|---|---|

| Wrote three subject lines and a headline for the campaign itself | Rule 1 — route, never do |
| "Step 5: Agent 69 — KPI Monitoring watches the ads daily" | Rule 3 — Agent 69 — KPI Monitoring is a parked automation, not available |
| "Key Result: grow YMCA pipeline 20%" | Rule 4 — Key Results word for word from the file; this target is invented |

| "I've added the 6 tasks to Asana" with no tool result in the chat | Rule 11 — a write is never done unless the tool said so |
| Ranked five initiatives for the quarter | BOUNDARY — that is Agent 2 — OKR Copilot |
