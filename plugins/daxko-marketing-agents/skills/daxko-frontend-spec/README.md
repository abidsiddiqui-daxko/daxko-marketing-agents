# Agent 30 — Frontend Development — teammate guide

**Skill:** `daxko-frontend-spec` · **Owner:** Abid Siddiqui · **Version:** 1.10.0

## What it does
Turns ONE web page or template into a **build spec in plain words** for the web publishing team: every section and part, what goes in each slot, how it behaves (menus, forms, errors), what changes on phone, tablet and desktop, accessibility needs, tracking and SEO bits, and a numbered "done when" list. It is for a Digital Services client's site by default; a Daxko page only if you ask.

## Requests to try
- "Build spec for our YMCA client's new homepage" (paste Agent 29 — UX/UI Design's wireframe)
- "Dev handoff for this wireframe"
- "Review this dev ticket — is anything missing?"

## Good to know
- It writes **no code** — no HTML, CSS or JavaScript. The web publishing team writes the code.
- It shows a checklist of 12 things a developer needs and asks you in short rounds (up to 3 questions at a time) until they are covered — or say "go ahead with what you have".
- It never invents the client's colours, links, form addresses or facts — gaps are marked `[needs: …]`.
- If you ask, it can put the spec in **one** Asana task or Google Doc — it first shows you exactly what it will create and waits for your "yes" in the chat. It never publishes a page, edits the website, deletes anything or sends anything to the client.
