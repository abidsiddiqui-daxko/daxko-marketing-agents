# Agent 3 — Market Intelligence & Competitive

**Ask it anything about Daxko's competitors or markets, and it answers from Daxko's own competitive files — with the file and date behind every line.** It also checks a rumour, news item or call note you paste against those files and tells you what is new, what matches and what contradicts them.

**Business owner:** Abid Siddiqui · **Skill name:** `daxko-market-intelligence` · **Batch 2** · first published v1.7.22

## Requests to try
> What do we know about TractionRec?

> Who are we up against when we sell Club Automation to medical fitness centers?

> Where do we win and lose against Amilia at a mid-size JCC?

> A rep heard PushPress dropped its price to $49 — what does that mean for us? [paste the note]

## What you get back
1. An **INTERNAL** label and a freshness line (competitor details were last enriched in May 2026)
2. The answer — a competitor brief, a landscape table, a head-to-head for your situation, or a signal check — every row with its source
3. Anything you pasted, marked **unverified**
4. **NOT ON FILE** — what Daxko's files don't cover (it never fills gaps from memory)
5. The Key Result it serves, one next step, and the list of files it read

For a signal check it also drafts a **Market Insight** record. It never edits Daxko's files — send the draft to Abid Siddiqui to add.

## What it will NOT do
| Ask | Who owns it |
|---|---|
| A vs / comparison / alternative page, a battle card, a teardown | `daxko-competitor-alternatives` |
| Sales one-pagers, deck outlines, demo talk tracks | Agent 21 — Sales Enablement (`daxko-sales-kit`) |
| Objection answers, battle cards | Agent 20 — Battlecard & Objection Handling (`daxko-battlecards`) |
| Themes across pasted reviews or feedback | Agent 50 — Product Insights & Feedback (`daxko-feedback-insights`) |
| Finding new reviews online | `daxko-customer-research` |
| Who we sell to, buyer pains, value props | Agent 5 — ICP & Value Prop |
| Any customer-facing copy | Agent 13 — Content Production or the brand copywriters |
| Searching the web for the latest news | Nobody — paste the article and it will check it |

## Good to know
- It never says an AI feature is available unless Daxko's product file lists it as in production. AI Agents and Member Intelligence 360° are treated as **not confirmed**.
- For CrossFit / functional-fitness gyms it names **Exercise.com** as the Daxko product, and flags that the competitor file still compares against Zen Planner.
- Personal contact details in a pasted note are left out.
- Corrections go to Abid Siddiqui (`learnings/agent-03-market-intelligence.md`).
