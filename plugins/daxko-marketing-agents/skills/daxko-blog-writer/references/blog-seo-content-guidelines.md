# SEO Content Guidelines: Evergreen & Longtail Blogs (all three brands)

```text
SEO Content Guidelines: Evergreen & Longtail Blogs
For: Zen Planner (SMB), Club Automation (Enterprise), Daxko (Nonprofit)
📁 File Naming Convention
Format: Assignment Code <Space> Blog Title
Example: LT ZP 71 - Best Billing Software for Boutique Fitness Studios in 2025
📁 Blog Length
Word Count: 700–900 words
📁 Blog Banner Guidelines
 Size: 1280 × 720 pixels (YouTube thumbnail standard)
 NO vector graphics
 Image link: Only use Google Drive URLs (not Freepik or external sources)
📁 Tone of Voice
 Zen Planner: Friendly, supportive, SMB-owner speak
 Club Automation: Enterprise-level, polished, confident but not salesy
 Daxko: Community-focused, professional, operationally thoughtful
 All Brands:
o Avoid fluff, wordiness, or jargon
o Aim for grade 7–8 readability
o Use American conversational tone
o Prefer active voice and crisp, informative sentences
📁 SEO Guidelines
✅ Keyword Placement
 Primary keyword in:
o Title (under 60 characters)
o Meta Description (155–160 characters)
o First paragraph
o At least 2 H2s
o Natural body text (max 3 times per blog)
 Use keyword variations from the Keyword Sheet (e.g., "gym management software" = use
variations like "fitness studio software", "gym scheduling tool", etc.)
❌ Do Not:
 Overuse primary keyword (>3 times)
 Partially hyperlink keywords (e.g., link only "software" in "gym management software")
 Spin content for related longtail topics
📁 Internal Linking
 Always use relevant interlinking
 Anchor text should reflect actual page intent (e.g., don't hyperlink 'Zen Planner' to a blog post)
 Use full keyword or phrase as anchor (not partial words)
 Refer to:
o Post Sitemap – for blogs
o Page Sitemap – for product pages
📁 CTA Placement
 Use specific CTA URLs depending on blog intent:
o Zen Planner Demo: https://lp.zenplanner.com/demo/
o Zen Planner AI: https://landing.zenplanner.com/engage-ai
o SugarWOD: https://www.sugarwod.com/get-started/ or /demo
o Club Automation: https://www.clubautomation.com/demo
o Daxko: https://www.daxko.com/demo
📁 Formatting Requirements
 Use proper heading structure:
o H1 = Title (should not exceed 60–65 characters)
o Minimum 2 H2s per blog
o Logical hierarchy (H2 > H3 > H4)
 Add tags to every blog:
o Title/H1, H2, H3, H4 as required
o Be explicit in drafts
📁 Red Flags to Avoid
 Repetitive “How to” titles (use varied title formats)
 Reusing same outlines or spun content across longtail topics
 Overly lengthy titles (ideal length: 50–65 characters)
```
