# Agent 29 — UX/UI Design — teammate guide

**Skill:** `daxko-ux-design` · **Owner:** Abid Siddiqui · **Version:** 1.7.37

## What it does
Designs a Digital Services client's website pages **in words**: a wireframe block by block (desktop and mobile), the list of parts the site needs, a simple design-system outline, or a review of a layout you paste. It uses only the brand and content you paste. A Daxko page only if you ask — then Daxko's own brand files (Barlow font) apply.

## Requests to try
- "Wireframe the homepage for our YMCA client's new site" (paste their colours and goals)
- "What components does this JCC site need?"
- "Design system outline for this club client"

## Good to know
- It asks up to 3 short questions first.
- No pictures, no code, nothing written into Figma or the website.
- It never invents the client's colours, fonts, photos, testimonials or facts — gaps are marked `[needs: …]`.
- Sizes and best practice are labelled "general practice, not a Daxko rule". It never says a design "passes" accessibility.
