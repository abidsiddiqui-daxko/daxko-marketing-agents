# Agent 35 — Web Content — teammate guide

**Skill:** `daxko-web-content` · **Owner:** Abid Siddiqui · **Version:** 1.7.37

## What it does
Writes website copy for a Digital Services client (a YMCA, JCC, Boys & Girls Club, health club or studio whose site Daxko builds or runs): one to three pages, a blog post for the client's own site, a rewrite of page copy you paste, or page titles and meta descriptions for a page list. It first asks up to 3 short questions — the client's facts, the page and reader, any keyword or limits — and uses only what you paste for the client.

## Requests to try
- "Write the homepage for the Riverbend YMCA's new site" (then paste the client's facts)
- "Rewrite this client's membership page" (paste it)
- "Page titles and metas for our client's 12 pages" (paste the list)

## Good to know
- Client facts (programs, hours, prices, reviews) come only from you. Anything missing is marked [needs: …].
- It never invents testimonials, awards, rankings or prices, and never promises Daxko's own results to a client.
- It uses a nonprofit client's own words (a YMCA "branch", a JCC "center", a Boys & Girls Clubs "Club").
- It publishes nothing. It reads a connector only if you say yes, read-only.
